# 🌐 Fundamentos de JavaScript

Conceptos básicos de JavaScript para desarrollo web.

## 📚 Temas Cubiertos

- Variables (var, let, const)
- Tipos de Datos
- Operadores
- Estructuras de Control
- Funciones
- Objetos y Arrays
- Métodos de String y Array

## 📝 Contenido

### Variables
```javascript
let nombre = "Juan";
const PI = 3.14159;
var edad = 25;
```

### Funciones
```javascript
function saludar(nombre) {
    return "Hola, " + nombre;
}

const suma = (a, b) => a + b;
```

### Objetos y Arrays
```javascript
const persona = {
    nombre: "María",
    edad: 30,
    saludar: function() {
        console.log("Hola");
    }
};

const numeros = [1, 2, 3, 4, 5];
```
