# 💻 Ejercicios Prácticos de TypeScript

Ejercicios para practicar TypeScript.

## 📝 Ejercicios Propuestos

### Nivel Básico
1. Definir tipos para objetos comunes
2. Crear interfaces simples
3. Funciones tipadas
4. Arrays tipados
5. Tipos unión

### Nivel Intermedio
1. Interfaces complejas
2. Clases con herencia
3. Genéricos simples
4. Tipos condicionales
5. Composición de tipos

### Nivel Avanzado
1. Genéricos avanzados
2. Decoradores
3. Mapped types
4. Conditional types
5. Módulos y namespaces

## 🎯 Cómo Usar Esta Carpeta

1. Elige un ejercicio
2. Implementa la solución con TypeScript
3. Compila el código
4. Verifica que no haya errores de tipo

## 📚 Herramientas

- Visual Studio Code
- TypeScript Compiler
- ts-node
- Playground de TypeScript
