# 🎓 Proyectos Integradores de Java

Proyectos completos que integran varios conceptos de Java.

## 📋 Proyectos Desarrollados

### 1. Sistema de Gestión de Estudiantes
Aplicación para gestionar información de estudiantes, calificaciones y generar reportes.

**Características:**
- Crear, leer, actualizar y eliminar estudiantes
- Registro de calificaciones
- Cálculo de promedios
- Persistencia en archivos

**Conceptos utilizados:**
- POO (Clases, Herencia)
- Colecciones (ArrayList, HashMap)
- I/O (Lectura/Escritura de archivos)
- Excepciones

### 2. Aplicación de Tienda Online
Simulación de una tienda online con carrito de compras y gestión de productos.

**Características:**
- Catálogo de productos
- Carrito de compras
- Cálculo de totales
- Historial de compras

**Conceptos utilizados:**
- POO (Interfaces, Polimorfismo)
- Colecciones
- Persistencia de datos

### 3. Juego de Aventura de Texto
Juego interactivo basado en texto con sistema de inventario y combate.

**Características:**
- Mundo interactivo
- Sistema de inventario
- Combate contra enemigos
- Guardado de progreso

**Conceptos utilizados:**
- POO
- Estructuras de control
- Colecciones
- Archivos

## 🎯 Objetivos

- Integrar múltiples conceptos de Java
- Trabajar con código más grande y complejo
- Practicar buenas prácticas de programación
- Crear portafolio de proyectos
