# ☕ Fundamentos de Java

En esta sección encontrarás los conceptos básicos de la programación en Java.

## 📚 Temas Cubiertos

- Variables y Tipos de Datos
- Operadores
- Estructuras de Control (if/else, switch)
- Bucles (for, while, do-while)
- Arrays y Listas
- Métodos y Funciones

## 📝 Contenido

### Variables y Tipos de Datos
```java
int numero = 10;
double decimal = 3.14;
String texto = "Hola Java";
boolean bandera = true;
```

### Estructuras de Control
```java
if (condicion) {
    // código
} else {
    // código alternativo
}
```

### Bucles
```java
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```
