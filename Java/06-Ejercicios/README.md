# 💻 Ejercicios Prácticos de Java

Colección de ejercicios para practicar los conceptos de Java.

## 📝 Ejercicios Propuestos

### Nivel Básico
1. Calculadora simple
2. Número secreto (juego)
3. Tabla de multiplicar
4. Palíndromo
5. Conversiones de temperatura

### Nivel Intermedio
1. Gestión de contactos
2. Lista de tareas
3. Sistema de calificaciones
4. Ordenamiento de números
5. Generador de contraseñas

### Nivel Avanzado
1. Sistema bancario
2. Gestor de biblioteca
3. Red social simulada
4. Juego de rol
5. Aplicación de inventario

## 🎯 Cómo Usar Esta Carpeta

1. Selecciona un ejercicio del nivel que desees
2. Implementa la solución
3. Prueba tu código
4. Compara con ejemplos de solución

## 📚 Temas Cubiertos

- Estructuras de control
- Métodos y funciones
- Clases y objetos
- Colecciones
- Excepciones
- Archivos

*Los ejercicios están diseñados para reforzar los conceptos aprendidos en cada tema.*
