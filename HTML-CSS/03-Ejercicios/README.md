Ejercicios para practicar maquetación web.

## 📝 Ejercicios Propuestos

### Nivel Básico
1. Página personal
2. Blog simple
3. Portfolio básico
4. Landing page
5. Catálogo de productos

### Nivel Intermedio
1. Diseño responsivo completo
2. Página de empresa
3. Tienda online (estructura)
4. Dashboard admin
5. Sitio de noticias

### Nivel Avanzado
1. Diseño completo de marca
2. Plataforma de servicios

4. Aplicación web (UI)
5. Portafolio profesional

## 🎯 Cómo Usar Esta Carpeta

1. Selecciona un ejercicio
2. Implementa HTML y CSS
3. Prueba en diferentes dispositivos
4. Asegúrate de que sea responsivo

## 📚 Enfoque

- Semántica correcta
- Diseño responsivo
- Accesibilidad
- Performance
- Buenas prácticas
