# 💻 Ejercicios Prácticos de SQL

Ejercicios para practicar SQL.

## 📝 Ejercicios Propuestos

### Nivel Básico
1. Crear base de datos de tienda
2. Insertar datos en tablas
3. Consultas SELECT simples
4. Filtrar con WHERE
5. Ordenar resultados

### Nivel Intermedio
1. JOINs entre tablas
2. Funciones de agregación
3. GROUP BY y HAVING
4. Actualizar y eliminar datos
5. Subconsultas

### Nivel Avanzado
1. Vistas complejas
2. Transacciones
3. Índices y optimización
4. Procedimientos almacenados
5. Triggers

## 🎯 Cómo Usar Esta Carpeta

1. Crea una base de datos
2. Resuelve cada ejercicio
3. Verifica los resultados
4. Compara con soluciones

## 📚 Herramientas Recomendadas

- MySQL Workbench
- pgAdmin (PostgreSQL)
- DBeaver
- SQLite Browser
